# 공룡 게임 · 개발 검증 브랜치

공룡 퀴즈(이름·시대·먹이)와 9조각·16조각 퍼즐을 기존 호수플레이와 격리된 `/dinosaurs/` 경로에 만들었습니다.

## 아직 배포하지 않은 이유

- 워크의 **최종 30종 이미지 및 기존 로컬 변경 코드가 GitHub에 올라오지 않았습니다.**
- 지금 `data.js`는 라이브러리에서 **고유 이미지 1개씩 확인한 12종**만 임시로 담고 있습니다. 이것을 30종 전체로 간주하지 마세요.
- `images/<영문-id>.webp` 경로로 이미지를 찾습니다. 현재 브랜치에는 이미지 파일이 없고, 퀴즈는 텍스트 특징으로도 풀 수 있지만 그림 퍼즐은 **이미지 업로드 전 동작하지 않습니다.**
- 메인 페이지의 공룡 **준비중** 배지는 배경 그림에 합성돼 있으므로 이미지 자산 없이 메뉴 링크만 활성화하지 않습니다. 메인 메뉴는 건드리지 않았습니다.

## 포함된 동작

- 10문제씩 중복 없이 출제하는 이름/시대/먹이 퀴즈
- 처음 시도에 맞히면 1점, 오답을 누른 뒤 정답이면 0점
- 정답 텍스트/음성 안내 후 약 1.5초 뒤 다음 문제로 자동 이동
- 음성 읽기에서 이모지 제거, 음성 미지원 시 텍스트만으로 진행
- 첫/마지막 문제, 반복 실행, 화면 전환 시 예약된 자동 넘김 해제
- 9·16조각 퍼즐(클릭/터치로 조각 선택 후 빈칸 선택, PC는 드래그 가능), 완성 판정 및 다시 시작

## 검증

`node dinosaurs/tests/quiz-core.test.cjs`

추가로 GitHub에서 읽은 최신 코드를 이용해 문제 출제, 오답/정답 점수, 자동 이동, 끝 화면, 재시작, 9·16조각 퍼즐의 상태 흐름을 모의 DOM에서 검증했습니다. 실제 브라우저와 30종 이미지 로딩 검증은 **아직 완료하지 못했습니다.**

## 공개 전 체크

1. 워크의 30종 최종 파일과 이름·시대·먹이 데이터 목록 대조 (중복·콜라주 제외)
2. 해당 이미지의 각 파일명·용량·설명과 게임의 연결 확인
3. 실제 Chrome / 모바일 Safari / Android Chrome에서 퀴즈·음성·퍼즐 확인
4. 기존 공룡 메뉴의 준비중 배지를 새 이미지로 교체하고 링크 연결
5. 사용자 확인 뒤 `main`에 병합하고 GitHub Pages 배포
