# 호수플레이 공룡 놀이

공룡 30종의 공통 데이터와 자체 생성 복원 그림을 사용합니다. 정적 HTML/CSS/JavaScript로 동작하며 빌드 과정은 없습니다.

## 화면과 동작

- `/dinosaurs/`: 힌트 이름 퀴즈 → 시대·먹이 퀴즈 → 퍼즐 → 도감 순서.
- 이름 퀴즈: 한 회차에 30종을 중복 없이 섞고 보기 4개를 제공합니다. 힌트는 시대, 먹이, 형태, 특징 순으로 한 개씩 표시합니다. 정답은 5점에서 본 힌트 수만큼 차감하며 최소 1점입니다.
- 시대·먹이 퀴즈: 30문항에서 먹이와 시대를 번갈아 묻습니다. 정답은 5점입니다. 먹이 보기의 잡식은 오답 선택지이며 현재 30종 데이터는 초식·육식으로 구성합니다.
- 두 퀴즈 모두 답을 고른 뒤 일반 문장으로 정답과 점수를 말하고, 음성이 끝나면 자동으로 다음 문항으로 이동합니다. 다음 버튼은 없습니다. 이모지를 음성으로 읽지 않습니다. 음성 미지원 시 짧게 결과를 보여준 뒤 이동하며, 완료 이벤트가 없는 브라우저는 9초 뒤 진행합니다.
- `/puzzle/?category=dinosaur`: 기존 터치/클릭/드래그 퍼즐 엔진의 9·16조각을 재사용합니다. 퀴즈 목록으로 돌아오면 공룡 메뉴로 이동합니다.
- 도감: 모든 30종, 시대별 필터, 이름·특징 듣기, 자연사박물관 출처 링크.

## 파일

- `dinosaur-data.js`: 공룡 ID, 한국어 이름, 시대, 먹이, 힌트 4개, 그림 경로, 출처.
- `dinosaur-quiz.js`: 퀴즈/도감과 음성·자동 진행 상태 관리.
- `dinosaurs.css`: 기존 곤충 페이지의 시각 스타일을 기반으로 한 공룡 화면 스타일.
- `images/*.webp`: 960px 정사각형 복원 그림 30장.
- `image-prompts.json`: built-in image_gen으로 생성한 이미지의 프롬프트 기록. 플라테오사우루스는 두 발 자세로 보완했습니다.
- 상위 `puzzle-categories.js`, `puzzle.js`, `playroom.js`, `playroom.css`와 세 진입 HTML이 메뉴·퍼즐을 연결합니다.

## 자료와 표현

각 데이터의 `source`에 Natural History Museum Dino Directory 항목이 연결되어 있습니다. 그림은 AI 복원도이며 실제 색상과 일부 외형은 추정이라는 문구를 화면에 표시합니다. 물고기를 먹는 공룡은 육식에 포함합니다. 체격 비교용 축척 그림은 아닙니다. 코엘로피시스는 트라이아스기의 대표 종을 기준으로 설명합니다.

## 확인한 내용

- 공룡 ID 30개, 그림 파일 30개, 힌트 각 4개.
- 두 퀴즈 60문항의 정답·오답, 점수, 보기 중복 방지, 이중 답변 방지, 마지막 결과, 도감 필터: DOM 기반 자동 검사 통과.
- 이모지 없는 정답 음성, 음성 종료 후 정확히 한 번 자동 진행, 메뉴 복귀 시 진행 취소: 자동 검사 통과.
- 실제 앱 내 브라우저에서 이름 퀴즈의 4단계 힌트·그림 공개·1점, 탐구 퀴즈 자동 다음 문제, 9/16조각 퍼즐 완성 및 공룡 메뉴 복귀 확인.

## 유지보수 시 주의

공룡 데이터는 퀴즈와 퍼즐에서 함께 사용하므로 ID와 그림 경로를 함께 관리합니다. JavaScript를 변경하면 HTML의 버전 쿼리를 올려 기존 캐시와 새 HTML이 섞이지 않게 합니다. 생성 이미지 원본을 다시 만들 필요는 없습니다. 새 기기의 음성·터치 조작은 해당 기기에서 추가 점검할 수 있습니다.
